# Application brand asset

`app-logo.png` was supplied from [Icons8](https://icons8.com/icon/nAYITb36Rm9S/key).
`app.ico` is the same image exported at multiple Windows icon sizes for the
desktop window, taskbar, shortcuts, and packaged executable.

The ICO contains 16, 24, 32, 48, 64, 128 and 256px entries. The same local file
is embedded in the EXE and installer; branding does not depend on a runtime URL.
Release tooling verifies all seven EXE sizes and includes the attribution in
third-party notices. Confirm the asset's distribution rights before publishing.
